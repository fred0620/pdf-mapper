# 發版檢查清單

每次發布前確認一次。標「自動」的由 CI 或測試檢查，pipeline 是綠的就算通過。公司另有規定時，以公司規定為準。

```text
[ ] 1. 只在本機執行：服務只綁 127.0.0.1，擋外部 Host 與跨站請求（自動）
[ ] 2. 不傳資料出去：新增的程式沒有呼叫任何外部網址
[ ] 3. 日誌不記內容：新增的 log 不記檔名、PDF 內容和抓到的值
[ ] 4. 資料只放 workspace：新功能沒有把資料寫到 workspace 以外的地方
[ ] 5. 套件鎖版本且沒有已知弱點（自動：uv lock --check、pip-audit）
[ ] 6. 發布包不含資料：只打包明確列出的檔案（自動：build_release.py）
[ ] 7. 有疑慮就標記：解析邏輯的修改沒有把「標記給人確認」改成「直接猜值」
[ ] 8. CHANGELOG 寫了這版改了什麼（自動：沒寫不能發布）
```

## 已經內建、修改時要維持的

- 本機服務擋 DNS rebinding 與跨站請求，回應加上安全標頭。
- 上傳只收 PDF，檔名去掉路徑與不安全字元，暫存在結束時刪除。
- Excel 文字儲存格強制文字格式，防公式注入。
- 錯誤畫面只顯示一般訊息，細節只寫本機日誌。
- 下載 uv 與安裝新版時都會驗證檔案，失敗就保留原版本，使用者可以自行退回。

詳細原因見 [設計決策](design.md#資訊安全2026-11-09-review)。
