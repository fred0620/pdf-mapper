# 資安檢查清單

不另訂一套規範。先對照公司既有的 EUC、資料分級與資安政策，這份清單只整理「這個工具怎麼符合」，以及每次發版要確認的項目。

## 風險分級

用兩個問題決定要做多少：

| | 輸出不直接影響錢、合約或報關 | 輸出會直接影響錢、合約或報關 |
|---|---|---|
| **只碰公開或一般資料** | 輕量級 | 標準級 |
| **碰到內部、機密或個人資料** | 標準級 | 重要級：先找 IT 或資安一起評估，不要自己發布 |

- **輕量級**：每次發版做基本項目。
- **標準級**：基本項目，加上標準級項目。
- 本工具的分級記在 [OWNER.md](../OWNER.md)。

## 基本項目（每次發版）

把下面這段複製到 Merge Request 或 Release 說明，逐項勾選。標「自動」的由 CI 或測試檢查，只要確認 pipeline 是綠的。

```text
[ ] 1. 只在本機執行：服務只綁 127.0.0.1，擋外部 Host 與跨站請求（自動：tests/test_server.py）
[ ] 2. 不連外：執行時不傳資料到外部；新增的程式沒有呼叫外部網址
[ ] 3. 日誌不記內容：新增的 log 只記 doc_id、run_id、範本代號與數量，不記檔名、PDF 內容和抓到的值
[ ] 4. 暫存會清：上傳的 PDF 在結束時刪除，新功能沒有在 workspace 以外留下資料
[ ] 5. 依賴鎖版本：uv.lock 與 pyproject.toml 一致（自動：uv lock --check）
[ ] 6. 依賴沒有已知弱點：pip-audit 通過（自動：打標籤時強制）
[ ] 7. 發布包可驗證：latest.json 的 SHA256 與 ZIP 相符，啟動程式驗證不符就不安裝（自動：build_release.py）
[ ] 8. 發布包不含資料：只打包明確列出的檔案，dist/ 裡沒有 workspace 或真實 PDF
[ ] 9. 輸出防公式注入：Excel 文字儲存格去控制字元並強制文字格式（自動：tests/test_parser.py）
[ ] 10. 錯誤不外洩：畫面只顯示一般訊息，細節只寫進本機日誌
[ ] 11. 發布權限：版本標籤受保護，共用資料夾只有負責人可寫入
```

## 標準級項目

```text
[ ] 12. 有疑慮就標記：解析邏輯的修改沒有把「標記給人確認」改成「直接猜值」
[ ] 13. 真實資料回歸：改到解析邏輯時，用本機的真實樣本（不進版控）跑過一次，結果與上一版比對
[ ] 14. 工具卡是最新的：負責人、備援人、資料等級沒有變動，或已更新 OWNER.md
[ ] 15. 已知會 IT 或資安：第一次發布、資料等級改變，或新增任何連網行為時
```

## 設計上已經做到的事

發版時不用重新檢查，但修改相關程式時要維持。詳細原因見 [設計決策](design.md#資訊安全2026-11-09-review)。

- 本機服務只接受 Host 為 127.0.0.1 或 localhost 的請求，`/api/` 拒絕跨站請求。
- 回應加上 CSP、X-Frame-Options、nosniff 等標頭，API 回應不快取。
- 上傳只收 `%PDF-` 開頭的檔案，檔名去掉路徑與不安全字元。
- 日誌輪替 1 MB × 5 份，30 天以上刪除，外部字串去控制字元。
- 啟動程式下載 uv 與新版工具時都比對 SHA256，不符就停止。
- 更新失敗時保留原版本；新版有問題時使用者可以自行退回。
- 負責人可以在 `latest.json` 設定停用，讓所有人停止使用有問題的版本。

## 刻意保留的風險

- **執行原則**：`run.bat` 以 `-ExecutionPolicy Bypass` 啟動 PowerShell，沒有程式碼簽章。公司若要求只能執行簽章過的腳本，請 IT 協助簽章 `app/launcher.ps1`，不要讓使用者自行解除封鎖。
- **第三層客製腳本**：`--post` 會執行指定的 Python 檔，等同使用者自己執行程式。只放在使用者自己的 `workspace/custom`，發布包不含任何客製腳本。
- **匯出檔**：`workspace/output` 的 Excel 含截圖與資料，不會自動刪除，由使用者依公司規定保管。
