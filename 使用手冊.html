PDF 解析器使用手冊

這個工具把格式相同的 PDF 批次轉成 Excel。你只要在一份範例上標出「資料在哪裡」，之後同格式的 PDF 就能自動抓取。抓得不確定的值會標出來，由人確認。

所有處理都在你自己的電腦上進行，檔案不會上傳到任何地方。

1. 三個基本觀念

名詞 意思
範本 一份「資料在哪裡」的地圖。一種單據版本建一份，之後重複使用
基準範例 用來標注的那份 PDF，也就是加入的第一份
定位點 每份單據都不會變的文字，例如表單標題。工具靠它校正位置，所以單據稍微歪掉或偏移也抓得到

使用分成兩階段：

  1. 建立範本：每種單據做一次，由熟悉單據的人操作。
  2. 解析 PDF：之後每次要處理新檔案時使用。

2. 安裝與啟動

第一次安裝

不需要先安裝 Python，工具會自己準備。

步驟一：下載工具。 到 GitHub 專案頁，按綠色 Code 按鈕，選 Download ZIP。

步驟二：解壓縮。 解壓到固定位置，例如 文件\pdf-mapper。不要在壓縮檔裡直接執行。

步驟三：啟動。

  • Windows：雙擊 start.bat。如果出現「Windows 已保護您的電腦」，按「其他資訊」再按「仍要執行」。
  • macOS：開啟終端機，進入資料夾後輸入 bash start.sh。

第一次會自動下載 uv、Python 3.12 和所需套件，約 1 到 3 分鐘，需要連網。完成後瀏覽器會自動開啟工具。

這些東西全部放在工具資料夾內的 .tools 和 .venv。電腦上原本的 Python 不受影響，也不會改動系統設定。不想用了，刪掉整個資料夾就好。資料夾移動位置後，請刪除 .venv，下次啟動會重建。

之後每次使用

雙擊 start.bat 就好。那個黑色視窗就是工具本身，使用時不要關掉。

用完時，關閉瀏覽器頁面或黑色視窗都可以。關閉頁面約 10 秒後，工具會自動結束，黑色視窗也會跟著關閉。正在解析時關閉頁面，工具會等解析完才結束，但結果來不及匯出就會消失。工具已經開著時再雙擊 start.bat，只會開啟原本的工具，不會多開一個。

工具右上角的「使用手冊」連結可以隨時開啟這份手冊。

公司電腦不能連網，或擋 GitHub

  1. 找一台能連網、作業系統和 CPU 架構都相同的 Windows 電腦。
  2. 在專案資料夾的 PowerShell 執行 .\scripts\build_offline_bundle.ps1，會準備好 .tools 和 wheels。
  3. 把整個資料夾複製到目標電腦，但不要複製 .venv 和 .tools\cache。
  4. 雙擊 start.bat，工具會自動改用離線安裝，全程不連網。

3. 先試用：五分鐘看懂流程

工具內附虛構的報單範例和做好的範本，可以先試：

  1. 點上方的「解析 PDF」。
  2. 「使用範本」勾選 進口報單（示範） 和 商業發票（示範）。
  3. 按「加入 PDF」，選 samples 資料夾裡全部的 PDF。
  4. 按「開始解析」。工具會逐份挑最符合的範本，左邊會顯示每份用了哪個範本。
  5. 點左邊的 sample_5_errors.pdf。這份故意少一列，稅費合計也是錯的，可以看到工具怎麼標記。

4. 建立範本

4.1 準備範例

建議準備 3 份以上同種單據，包含明細較多、會跨頁的一份，以及格式略有不同的一份。

  1. 點上方的「建立範本」，在左上填範本名稱，例如「進口報單」。
  2. 把 PDF 拖進畫面。第一份會自動成為基準範例。基準範例要選明細有跨到第 2 頁的那份，才能標注續頁。

要調整範例時：

  • 移除一份：按檔名右邊的「×」。
  • 換掉整組：按清單下方的「全部移除」。範本和已標注的框線都會保留。
  • 換基準範例：按該份下方的「設為基準範例」。

更換基準範例時，已標注的框線不會自動移動，請逐一確認位置。移除基準範例時，清單中的下一份會自動成為基準範例。

4.2 標注有標題的欄位

適用於旁邊有欄位名稱的資料，例如「報單號碼」。

  1. 按工具列的「有標題的欄位」。
  2. 框住欄位名稱。

  1. 依綠色提示，再框住數值的範圍。框大一點沒關係，但不要碰到隔壁的資料。
  2. 右邊會立刻顯示抓到的內容。工具會繼續留在這個模式，可以連續標下一個欄位。

右邊可以改欄位名稱，並選資料類型。選「數字」或「日期」後，格式不對時會被標記。

4.3 標注只有值的欄位

適用於旁邊沒有欄位名稱，只能靠位置判斷的資料。按「只有值的欄位」，框住數值，再到右邊取名。這類欄位完全靠定位點找位置，請記得加定位點（見 4.5）。

4.4 標注表格

  1. 按工具列的「表格」，框住資料區。不要包含標題列，下緣框到明細可能出現的最底部。
  2. 在表格內點一下，就會切出一條直欄分隔線。依表格的直欄逐一切好。分隔線可以拖曳移動，雙擊可以刪除。

  1. 到右邊替每一欄命名。
  2. 選一欄「用這欄判斷新的一列」，通常是項次。這一步很重要，工具靠它判斷明細有幾列。

同一格有多行資料時：例如稅則欄有上下兩行，按該欄下方的「這一格有多行，再拆一欄」，再用「第幾行」區分。

明細會跨頁時：

  1. 切到第 2 頁。
  2. 選取表格後，按右邊的「在這一頁加範圍」。
  3. 框住第 2 頁的資料區。套用頁面維持「第 2 頁起」。

4.5 加定位點

每一頁至少要有 3 個定位點，而且要分散在頁面四周。 欄位標題會自動算成定位點，但只有第 1 頁有標題時，續頁就要另外加。

  1. 切到要加的那一頁。
  2. 按右邊的「自動找這一頁的定位點」。
  3. 虛線框就是定位點。如果框到會隨單據變動的內容，例如日期或報單號碼，點它再按「刪除定位點」。

也可以按工具列的「定位點」手動框選。

4.6 加數字檢查（強烈建議）

這是防止錯誤最有效的方法。金額有加總關係時都建議加上。

  1. 右邊「數字檢查」按「新增檢查」。
  2. 選檢查方式：幾個欄位相加、表格某欄加總，或比對總頁數。
  3. 選好欄位後按「加入檢查」。

4.7 測試

按右下的「用 N 份範例測試」，左邊每份範例都會顯示結果，下方會列出抓到的資料。

點其他範例逐份檢查。特別留意：

  • 列數對不對
  • 長品名有沒有被截斷
  • 每一欄有沒有對到正確的資料
  • 跨頁的地方有沒有漏列

要修改時，先點回左邊第一份基準範例，測試範例上不能標注。

4.8 儲存

按「儲存範本」。範本存在 templates 資料夾。測試結果滿意再存；之後修改再存一次就會覆蓋。如果名稱和其他範本相同，工具會先問你要不要覆蓋。

4.9 建立下一個範本

存好後按右下的「開始新範本」，畫面會回到空白狀態：範本名稱、框線、定位點、數字檢查、測試結果和範例 PDF 都會清除，已儲存的範本不受影響。如果範本還沒儲存，工具會先提醒。

5. 解析 PDF

  1. 點上方的「解析 PDF」。
  2. 勾選範本。可以複選，不確定是哪一種單據時，就把可能的範本都勾起來。
  3. 拖入 PDF，可以一次放多份。加錯時按檔名右邊的「×」，或按「全部移除」換一組。
  4. 按「開始解析」。一般 PDF 通常每頁約 1 秒內，掃描檔每頁約數秒，視電腦而定。
  5. 逐份檢查右邊的「待檢查」項目： - 點項目，頁面會跳到該位置並框起來。 - 值是對的：直接按「確認」。 - 值是錯的：改成正確的值，再按「確認」。
  6. 按「匯出 Excel」。檔案會下載，同時保留一份在 output 資料夾。

選多個範本時

工具會先比對每個範本的定位點，再實際解析分數接近的範本，挑問題最少的那個。左邊清單會顯示每份用了哪個範本，右上方會列出各範本的符合度。

  • 兩個範本分數接近時，會標記「分數接近，請確認用對範本」。
  • 所有範本都找不到定位點時，會標記「可能沒有適用的範本」，這份的資料不要直接採用。

符合度看的是定位點，所以範本的定位點要選該單據獨有的文字。如果每個範本的定位點都是相似的內容，就比較難分辨。

重新按「開始解析」會產生全新結果，之前的人工修正不會保留。關閉頁面或工具後，尚未匯出的結果也會消失，瀏覽器會先提醒。請確認完再匯出。

6. 看懂 Excel

工作表 內容
待檢查 所有需要人看的項目，附原因和原圖截圖
檔案總覽 每份 PDF 用了哪個範本、符合度、挑選方式和檢查結果
欄位資料 每份 PDF 一列，並標示使用的範本
表格名稱 例如「貨物明細」，每個品項一列，並標示來自哪個檔案和哪一頁

一批 PDF 用到多個範本時，每個範本的資料會分開成各自的工作表，例如「欄位_進口報單」和「欄位_商業發票」，不同範本的欄位不會混在一起。

顏色 意思
橘色 需檢查，滑鼠移到儲存格可看原因
紅色 必填但沒抓到
綠色 已人工修正，註解有原始值

所有值都以文字原樣保存，例如 1,234.50 不會被改動。需要計算時，請在 Excel 轉成數字，或交由第三層客製化處理。

7. 標記的意思與處理方式

標記 原因 怎麼處理
影像辨識信心偏低 字跡不清或解析度低 對照原圖修正
文字層與影像辨識結果不同 兩種方式讀出來不一樣 對照原圖修正
文字層是亂碼，已改用影像辨識 PDF 內的文字無法解碼 核對這個值
文字層沒有內容，且影像辨識無法使用 影像辨識沒有成功載入 執行 .\start.ps1 doctor 檢查
內容壓到框線 框太小，可能少抓字 回到範本把框放大
內容跨到隔壁欄 分隔線不準，或文字本來就壓線 調整分隔線，或核對值
這一頁對位不穩 定位點太少或太集中 多加分散的定位點
這一頁找不到定位點 定位點都找不到 確認範本適用，或補定位點
欄位標題位置與其他欄位偏移不一致 這份版面可能不同 核對值，必要時另建範本
格式與設定不符 例如數字欄讀到文字 核對值或調整欄位類型
必填欄位沒有抓到值 該位置沒有內容 核對原檔或調整框
加總驗證不符 數字對不上 分別核對加總項目與合計
項次不連續 可能漏列 查看跳號的地方
這一列可能跨頁，已合併 一列被拆到兩頁 確認合併結果
可能不適用此範本 定位點找到不到一半 換範本，或為新版面建範本
兩個範本分數接近 自動選擇時難以分辨 確認用對範本，或替範本加上獨有的定位點
可能沒有適用的範本 選取的範本都找不到定位點 這份資料不要採用，為它建立範本

沒被標記不等於百分之百正確。 尤其是掃描檔，影像辨識可能以高信心讀錯字。金額等關鍵資料請設定數字檢查，或在欄位勾選「重要欄位，用影像辨識再核對一次」。新範本上線初期也建議抽查。

8. 進階設定

欄位和表格的「進階設定」平常不用動。以下是常見用法：

需求 設定
從「第1頁/共11頁」取出 11 從內容擷取：共\s*(\d+)\s*頁
統一編號必須是 8 碼數字 格式檢查：^\d{8}$
稅則格式檢查 格式檢查：^\d{4}\.\d{2}\.\d{2}\.\d{2}-\d$
只取框內第二行 取第幾行：2
項次格式不是純數字，例如 A01 新一列的格式：^[A-Z]\d+$
表格遇到「以下空白」就結束 遇到這段文字就結束表格：以下空白
項次固定在每列最上方 列判斷欄的位置：在列的最上方。這樣跨頁的半列會併回上一列

9. 管理範本

  • 備份與分享：範本就是 templates 裡的一個 JSON 檔。複製給同事，放進他的 templates 資料夾就能用。
  • 修改：在「建立範本」加入 PDF，再從「開啟已存的範本」選擇。要先加入同一份基準範例，框線才會對得上。
  • 單據改版：新版面請另存一份範本，例如「進口報單 2027 版」，舊版繼續用來處理舊單據。
  • 更新工具：下載新版 ZIP 後，把舊資料夾的 templates 複製到新資料夾。.venv 和 .tools 不用搬，第一次啟動會重新安裝。

10. 檔案與資料安全

資料夾 內容
templates 範本，請備份
output 匯出的 Excel
workspace 上傳到工具的 PDF 暫存複本

工具結束時會清除 workspace 裡的 PDF 暫存；如果是直接關閉黑色視窗或電腦當機，下次啟動時會清除。處理機密文件後若不打算再開工具，請手動刪除 workspace 資料夾。output 的 Excel 含截圖與資料，不會自動清除，請依公司規定保管。

不要把真實單據放進 GitHub。專案已設定忽略 workspace、output 和 samples 以外的 PDF。

11. 批次自動化（選用）

熟悉指令的人可以不開網頁，直接在 PowerShell 執行：

# 解析整個資料夾
.\start.ps1 run -t templates\進口報單.json -i D:\報單 -o output\結果.xlsx

# 多種範本時，每份自動挑最符合的
.\start.ps1 run -t templates -i D:\報單

# 匯出前套用第三層客製化
.\start.ps1 run -t templates\進口報單.json -i D:\報單 --post custom\example_transform.py

# 檢查環境
.\start.ps1 doctor

第三層客製化的寫法請參考 custom\example_transform.py。

12. 常見問題

顯示「無法下載 uv」或「環境建立失敗」 通常是公司網路阻擋 GitHub 或 PyPI，請改用第 2 節的離線安裝。

安裝到一半中斷 重新執行 start.bat 會接續完成。還是失敗時，刪除 .venv 和 .tools 再試一次。

瀏覽器沒有自動開啟 看黑色視窗裡顯示的網址，例如 http://127.0.0.1:8765，貼到瀏覽器。

畫面顯示「影像辨識無法使用」 文字層仍可讀取，但掃描內容讀不到。刪除 .venv 和 .tools 資料夾後重新啟動，讓工具重新安裝。

整欄資料都偏了一格 檢查分隔線位置，以及每個輸出欄對應的直欄。

表格列數不對 確認有選「用這欄判斷新的一列」，以及表格範圍有包含所有列。續頁要另外加範圍。

後面幾頁都抓不到 通常是續頁沒有定位點，或表格沒有加第 2 頁起的範圍。

畫面顯示「工具已經關閉」 黑色視窗被關掉了。重新執行 start.bat，再重新整理頁面。上傳的 PDF 需要重新加入，範本草稿會保留。

一份 PDF 顯示解析失敗 可能有密碼保護或檔案損毀，請先解除密碼或重新下載。其他檔案不受影響。

自動選錯範本 通常是定位點不夠有區別。替範本加上該單據獨有的文字當定位點，或解析時只勾選正確的範本。

測試很準，實際跑卻常被標記 範例不夠有代表性。把被標記的檔案加入範例，調整框線和定位點後重新儲存。
